Data Flow

How articles move from RSS feeds to your Kindle

Pipeline Overview
1. RSS Feeds
User adds feed URLs → stored in SQLite
↓
2. Feed Polling
Manual refresh or periodic → parse with feedparser → store new articles
↓
3. Browse & Select
Next.js UI shows articles by feed → read RSS summary → check articles for digest
↓
4. Full Content Fetch (on demand)
Selected articles → Trafilatura extracts clean markdown from source URL
↓
5. EPUB Generation (background task)
Markdown → EPUB via ebooklib → daily digest with table of contents
↓
6. Kindle Delivery (background task)
Send-to-Kindle email or KOReader OPDS catalog

Key Libraries

feedparser
Parse RSS/Atom feeds
trafilatura
Extract article content from URLs
ebooklib
Generate EPUB files
SQLite + aiosqlite
Store feeds, articles, digests
