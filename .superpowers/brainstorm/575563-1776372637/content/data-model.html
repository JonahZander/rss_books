Data Model & API

SQLite tables and API endpoints

SQLite Schema
feeds
  id          INTEGER PRIMARY KEY
  url         TEXT UNIQUE          -- RSS feed URL
  title       TEXT                 -- feed name
  site_url    TEXT                 -- link to the site
  last_polled DATETIME             -- last successful fetch
  created_at  DATETIME

articles
  id           INTEGER PRIMARY KEY
  feed_id      INTEGER REFERENCES feeds
  guid         TEXT UNIQUE          -- RSS guid, dedup key
  title        TEXT
  url          TEXT                 -- link to original article
  summary      TEXT                 -- RSS summary/description
  full_content TEXT NULL            -- Trafilatura markdown (fetched on demand)
  published_at DATETIME
  fetched_at   DATETIME NULL        -- when full content was fetched
  created_at   DATETIME

digests
  id          INTEGER PRIMARY KEY
  title       TEXT                 -- e.g. "2026-04-16"
  epub_path   TEXT NULL            -- path to generated EPUB file
  status      TEXT                 -- pending | generating | ready | sent
  sent_via    TEXT NULL            -- email | opds
  created_at  DATETIME
  sent_at     DATETIME NULL

digest_articles
  digest_id   INTEGER REFERENCES digests
  article_id  INTEGER REFERENCES articles
  position    INTEGER              -- order in the digest
API Endpoints
Feeds
GET    /api/feeds                  -- list all feeds
POST   /api/feeds                  -- add a feed {url}
DELETE /api/feeds/{id}             -- remove a feed
POST   /api/feeds/refresh          -- poll all feeds for new articles
POST   /api/feeds/{id}/refresh     -- poll one feed

Articles
GET    /api/articles               -- list articles (?feed_id=&unread=)
GET    /api/articles/{id}          -- get article detail
POST   /api/articles/{id}/fetch    -- fetch full content via Trafilatura

Digests
GET    /api/digests                -- list past digests
POST   /api/digests                -- create digest from selected article IDs
POST   /api/digests/{id}/send      -- generate EPUB + deliver to Kindle
GET    /api/digests/{id}/download  -- download the EPUB file
